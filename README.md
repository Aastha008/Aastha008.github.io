> An editorial, interactive digital portfolio and data playground designed around the creative arc:
> **HYPOTHESIS ──► EXPERIMENTATION ──► MODELS ──► DECISION INTELLIGENCE**

Crafted with inspiration from the cinematic pacing, oversized typography, and interactive storytelling philosophy of high-end digital design studios—translated into a joyful, high-contrast pastel data playground for **Aastha Gupta**, AI Analyst & Software Engineer at VIT Vellore.

## 🧭 Narrative Architecture

1. **Opening Hero**: *"DATA DOESN'T SPEAK. I BUILD THE REASONING THAT UNCOVERS TRUTH."* framed by an interactive data tool ribbon.
2. **Section 01 — Who Am I?**: *"ANALYTICAL RIGOR. ALGORITHMIC INTUITION. DECISION-GRADE CLARITY."* paired with an interactive ambient background playground morphing between `ANALYTICS`, `AI AGENTS`, `ML MODELS`, and `DECISIONS`.
3. **Section 02 — What I Build**: *"HOW I DISSECT COMPLEXITY."* featuring 4 core analytical pillars:
   - **ANALYZE**: Python, SQL, DuckDB, BigQuery, Power BI
   - **MODEL**: LangGraph, SciPy, Scikit-Learn, Isolation Forest
   - **BUILD**: Java 21, B+ Tree, FastAPI, React, TypeScript
   - **DECIDE**: SciPy, BigQuery, dbt Core, Power BI, DAX
4. **Section 03 — Selected Work**: High-contrast editorial project cards with interactive visualizers and deep-dive case studies:
   - **ForgeDB**: Relational database storage engine from scratch in Java 21 (slotted 4KB pages, LRU buffer pool, ACID ARIES recovery).
   - **DataPulse AI**: Autonomous Text-to-SQL analytics copilot over 547K+ records with self-healing LangGraph state machine & SciPy testing.
   - **PulseCart**: Enterprise analytics warehouse & randomized A/B checkout experimentation over 100K+ sessions with 74 DAX measures.
   - **Synapse**: Real-time AI observability & root-cause intelligence isolating cascading microservice failures in < 3s.
5. **Section 04 — Tools I Think With**: High-contrast typographic constellation revealing verified production evidence on hover.
6. **Section 05 — Built in Public**: Authentic GitHub telemetry (37 public repositories, 19 stars) and interactive contribution activity field.
7. **Section 06 — Experiments**: Scrapbook archive with sticky notes linking to real GitHub repositories.
8. **Section 07 — Beyond Code**: Creative pursuits exploring *Basketball*, *Design*, *Video*, and *Algorithmic Creative Tech*.
9. **Section 08 — Trajectory**: Editorial vertical timeline tracing academic and engineering milestones.
10. **Final Section**: *"LET'S MAKE SOMETHING COOL."* with direct contact channels.

## 🛠️ Technology Stack

- **Framework**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer
- **Motion & Scrolling**: Framer Motion, Lenis Smooth Scroll
- **Graphics & Visualizations**: Interactive Canvas & WebGL Morph Vector Fields, 3D Volatility Geometry
- **Icons**: Lucide React
- **Typography**: Space Grotesk, Inter, JetBrains Mono

## 🚀 Local Development

```bash
# 1. Install dependencies
npm install

# 2. Start local Vite development server with HMR
npm run dev

# 3. Build optimized production bundle
npm run build

# 4. Preview local production build
npm run preview
```
