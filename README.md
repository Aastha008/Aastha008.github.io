## ✨ Features & Highlights

- **Interactive 3D WebGL Visualization**: Built with Three.js featuring an ambient background particle canvas and an interactive **3D Volatility Surface Model** (modeling implied volatility smiles across strike prices and expiration dates).
- **Embedded Quantitative Finance Lab**: Real-time Black-Scholes option pricing solver calculating European Call/Put prices and analytical Greeks ($\Delta, \Gamma, \mathcal{V}, \Theta, \rho$).
- **Featured Projects Showcase**: Detailed architecture breakdowns, technical tags, and live deployment links for full-stack systems and data pipelines.
- **Categorized Technical Skills**: Modern breakdown spanning AI/LLMs, Database Systems, Data Engineering, Languages, and Analytics.
- **Responsive & Accessible**: Fully optimized for desktop, tablet, and mobile viewing with sleek glassmorphic UI elements.

## 🚀 Running Locally

No build step or Node.js server required!

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Aastha008/Aastha008.github.io.git
   cd Aastha008.github.io
   ```

2. **Open in browser:**
   - Double-click `index.html` or open via VS Code Live Server / Python HTTP server:
   ```bash
   python -m http.server 3000
   ```
   - Navigate to `http://localhost:3000`
